# Hyrule Hide & Seek v0.3.0

Requires mod protocol 7 for every player in the room. Use Dusklight 2.0.3 or newer with the default
public server. Older mod versions cannot join v0.3.0 rooms.

## Gameplay

- Random treasure rupees on native reachable ground, up to eight at once; each expires in 30 seconds.
- Three points per pickup and a five-point bonus for your third pickup. Every third round is
  Treasure Rush, with five points per rupee. Picking one up gives hunters a three-second clue.
- Host-confirmed manual and automatic taunts. Hiders see a pulsing reveal banner naming the cause,
  remaining reveal time and an upcoming-clue countdown.
- Three recommended free decoys, then three points per extra. Existing custom rules are retained.
- Two-second attack recovery after misses at the final quarter heart; a confirmed find restores
  one heart. The last hider receives eight-second clues in the final minute.
- Rules stay locked during a round; fair hunter rotation, random maps and session scores remain.
- Seven new selectable disguises: Ordon Ranch goat, village cat, Castle Town citizen and shopper,
  milk jar, market basket and shopping bag. Shared pedestrian animation archives are supported.
- Original theme colours and fonts retained, with cleaner spacing and compact layouts.
- Clean central HUD with compact role/timer cards, a temporary reveal alert, bounded nearby names,
  two nearby loot labels and small clue markers. Labels avoid overlap and truncate long names.
- Touch-sized menu controls, a layout that stacks on narrow screens, and a 16-player results table
  kept within screen bounds. Control hints are optional and off by default.
- Scoreboard adds loot and find counts.

## Multiplayer and hosting

- Default relay: `wss://hyrule-hide-and-seek.jhackerr.workers.dev`.
- Official Dusklight 2.0.3 fixes Linux WebSockets; Linux now uses the same transport as other platforms.
- Adaptive state updates: 10 Hz moving, 2 Hz stationary in rounds, 1 Hz stationary in lobbies.
- Compact prop states omit six Link animation slots. A 100 ms interpolation buffer and bounded
  extrapolation reduce jerky movement; large teleports snap.
- A bounded reliable queue protects rule/result messages; stale queued positions are replaced.
- Durable Object room hibernation and persistent indexed SQLite public listings.
- Public legacy HTTP polling disabled to conserve quota; private Node relays retain compatibility.

## Validation and limits

Linux build, over 2,900 rules/protocol/layout assertions, exact-case disc assets, native actor sweep, Node and Worker runtime relay tests, and
a small live Cloudflare lobby check passed. The local 200-player / 25-room synthetic test received
all 140,000 expected messages without cross-room delivery, at about 23 ms p95. This measures local
Node throughput, not Cloudflare latency or free daily capacity.

Cloudflare Free has finite daily allowances; continuously hosting hundreds of active players
cannot be guaranteed free. No paid subscription was enabled by deployment. Review
[server quota estimates](https://github.com/i12bp8/hyrule-hide-and-seek/blob/v0.3.0/server/README.md#free-tier-capacity) and the
[in-game checklist](https://github.com/i12bp8/hyrule-hide-and-seek/blob/v0.3.0/docs/testing.md).
Windows, macOS, Android and iOS runtime checks, full map balance and real cross-network
playtesting remain necessary.
