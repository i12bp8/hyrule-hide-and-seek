# Hyrule Hide & Seek v0.3.7

- Fix players being invisible when the game's root heap reports only 32767 KB free. Multiplayer
  models now use a dedicated 64 MiB heap backed by system memory, preserving the game's arena
  space and the full-room player/decoy budget.
- Retry temporary heap creation and model/animation archive failures instead of leaving other
  players invisible until the mod restarts. Preserve already copied model files during retries.
- Unlink the heap and animation archive before releasing their memory when the mod unloads.

Compatible with **v0.3.5–v0.3.6 rooms (protocol 10)**. Affected players need this update to see
other players. Use **Dusklight 2.0.3 or newer**.

Validated on official Linux Dusklight 2.0.3 with the root heap constrained to 32767 KB free:
all 15 remote Link puppets became visible in a 16-player lobby, all selectable prop kinds ran
with 160 decoys, and 167,031 draw-list checks passed through cleanup. Temporary heap and
model/animation mount failures recovered without restart. The rules suite passed 4,982 checks;
GCC and Clang builds passed. Other platforms still need runtime checks.
